# Airport Management System ✈️

A complete airport management web application developed using Flask and Python.

## Features
- Airport analytics dashboard
- Planes management
- Runways management
- Weather monitoring
- History tracking system
- Responsive user interface
- Organized backend architecture

## Technologies Used
- Python
- Flask
- HTML5
- CSS3
- JavaScript

## Project Structure
- Templates organization
- Static assets handling
- Backend routing and logic
- Responsive frontend pages

## Purpose
This project was built to improve backend development and software engineering skills by developing a real-world management system.
